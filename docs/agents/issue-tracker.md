# Issue Tracker — GitHub

Issues for this repo live in **GitHub Issues** on `tomeck91/LLMDashboard`.

- Remote: `origin` → `https://github.com/tomeck91/LLMDashboard.git`
- CLI: `gh` (installed at `C:\Program Files\GitHub CLI\gh.exe`; add to PATH or invoke by full path)
- Auth: requires a one-time `gh auth login`. Until authenticated, issue commands will fail.

## Conventions

- Create an issue for each discrete piece of work before implementing it (`to-tickets`).
- Link the commit/PR that closes an issue so history stays traceable.
- Use clear titles; put reproduction steps and expected vs. actual behavior in the body for bugs.

## PRs as a request surface

**Off.** External pull requests are not part of this repo's triage queue. (Flip to on if you later want inbound PRs handled through `triage`.)
